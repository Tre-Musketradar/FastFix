# Slutliga wireframes och mockups

Här läggs de wireframes och mockups som gruppen har bestämt att appen ska följa. De är underlaget när vi bygger frontend.

Utkasten som gruppen röstar om ligger i [`../utkast/`](../utkast/) och beskrivs i [frontendplanen](../../../frontend-plan.md#wireframes-och-mockups).

## Så blir ett utkast slutligt

1. Gruppen tittar på utkasten och röstar. Det som ska ändras skrivs ner.
2. Ändringarna görs i utkasten, och de nya bilderna läggs här med samma filnamn (`wireframe-…` och `mockup-…`).
3. Frontendplanen uppdateras så att den visar bilderna här i stället för utkasten.

Mappen är tom tills omröstningen är klar.
