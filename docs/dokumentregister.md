# Dokumentregister

Alla Markdown-dokument i repot, med datum då de lades till. Varje nytt dokument skrivs in här i samma pull request som lägger till det. Vad som har ändrats i ett dokument står i avsnittet "Ändringar" längst ner i dokumentet.

**Tillagd** är datumet då filen kom in i repot. För lärarens material står också **Från läraren**: datumet då filen sparades i projektmappen, ungefär när vi fick den.
