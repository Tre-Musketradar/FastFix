# Läxa till måndag (pass 3)

Ni har torsdag och fredag på er. På måndag ska varje grupp ha:

- ett repo och en board på GitHub som alla i gruppen har åtkomst till
- en prioriterad och storleksbedömd backlog med acceptanskriterier
- en första version av Definition of Done
- ett utkast till databasschema

Pass 3 handlar om Git i team, och då jobbar vi direkt i era repon. Därför måste de vara på plats till måndag.

## Läsordning

Läs **05** först. Den beskriver hur ni sätter upp repo och board, och det bör göras tidigt så att resten av läxan kan läggas direkt där. Läs sedan **01–04**.

## Uppgifter

### 1. Repo och board (ca 1 h)

- Läs `05-github-repo-och-board.md`.
- Skapa en GitHub-organisation för gruppen.
- Skapa projektets repo från mallrepot ("Use this template").
- Skapa en board i GitHub Projects och koppla den till repot.
- Kontrollera att **alla** i gruppen kan skapa issues och flytta kort.

### 2. Flytta in det ni gjort (ca 30 min)

Flytta in det ni gjorde till onsdag i `docs/` i repot:

- Gruppkontraktet i `docs/gruppkontrakt.md`
- MVP-beskrivningen i `docs/mvp.md`
- Preliminärt stackval som första post i `docs/beslutslogg.md`

### 3. User stories med acceptanskriterier (ca 2–3 h)

- Läs `01-acceptanskriterier.md`.
- Gå igenom era stories från onsdagen. Skriv om de som är för stora, för tekniska eller saknar "så att".
- Lägg in varje story som en issue med issue-mallen.
- Skriv 3–6 acceptanskriterier per story. Börja med de stories som hör till MVP:n. De som ligger längst ner i backloggen kan vänta.

### 4. Prioritera och storleksbedöm (ca 1 h)

- Läs `03-prioritering.md` och `04-estimering-klädstorlekar.md`.
- Märk varje story med MoSCoW (Must, Should, Could, Won't).
- Ordna backloggen så att det viktigaste ligger överst.
- Sätt en storlek på varje story: S, M eller L. Dela upp alla XL.

### 5. Definition of Done (ca 30 min)

- Läs `02-definition-of-done.md`.
- Skriv er första version i `docs/definition-of-done.md`. Börja enkelt: 5–8 punkter som alla förstår och kan följa.

### 6. Databasschema, utkast (ca 1–2 h)

- Utgå från era Must-stories. Vilka tabeller och fält behövs för att bygga dem?
- Rita schemat i t.ex. dbdiagram.io, drawSQL eller Excalidraw.
- Lägg bilden (och gärna källkoden om verktyget har det) i `docs/`.
- Det är ett utkast. Det blir klart i pass 3.

## Checklista inför måndag

- [ ] GitHub-organisation, repo och board uppsatta
- [ ] Alla i gruppen har åtkomst och har testat att skapa en issue
- [ ] Gruppkontrakt, MVP och beslutslogg inflyttade i `docs/`
- [ ] User stories inlagda som issues med acceptanskriterier
- [ ] Varje story har MoSCoW-prioritet och storlek
- [ ] Inga XL kvar i backloggen
- [ ] Definition of Done version 1
- [ ] Utkast till databasschema i `docs/`
