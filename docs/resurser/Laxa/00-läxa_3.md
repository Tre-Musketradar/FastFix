# Läxa till måndag: sprint 1 börjar

På måndag börjar sprint 1. Vi gör sprint planning tillsammans, och sedan bygger ni på riktigt. Allt nedan ska vara klart så att planeringen kan gå snabbt och ni kan börja koda direkt efteråt.

Ni har torsdag och fredag på er.

## Läsordning

1. **01–03** handlar om hur sprintarna fungerar. Läs dem före måndag.
2. **04–06** handlar om Git i vardagen. Läs 04 och 05 ordentligt. Ha 06 som uppslag när något går fel.

## Uppgifter

### 1. Det som inte blev klart till idag (varierar)

Gå igenom läxan från pass 3. Allt där ska vara klart innan sprint 1:

- `main` skyddad, med krav på pull request och godkännande
- PR-mallen stämmer med er DoD
- projektskelettet mergat
- databasschemat klart

### 2. Skelettet startar hos alla (ca 30 min)

Alla i gruppen, var för sig:

```bash
git switch main
git pull
```

Följ sedan README steg för steg och starta projektet. Om något inte fungerar: rätta README eller skelettet via en pull request.

Det här är viktigt. Den som inte kan starta projektet på måndag förlorar halva första sprinten.

### 3. Backloggen redo för planering (ca 1–2 h)

Product Owner ansvarar, men gör det gärna tillsammans. Läs `02-sprint-planning.md` först.

- De översta korten i backloggen ska vara **redo**: acceptanskriterier, storlek, och inga XL.
- Ha ungefär **dubbelt så mycket** redo som ni tror att ni hinner i sprint 1. Det ger utrymme att välja.
- Kontrollera ordningen: ligger det som andra kort bygger på först?

### 4. Välj den första storyn (ca 15 min)

Läs avsnittet om den första storyn i `02-sprint-planning.md`. Välj vilken story ni ska bygga **tillsammans** i början av sprint 1. Den ska gå genom alla lager men inte vara för stor.

### 5. Roller för sprint 1 (ca 10 min)

Bestäm vem som är **Product Owner** och **Scrum Master** under sprint 1. Läs om rollerna i `01-sprintrytmen.md`.

### 6. Gruppkontraktet (ca 15 min)

Lägg till två saker i `docs/gruppkontrakt.md`, via en pull request:

- När ni har daily standup, och att Scrum Master loggar den
- Hur snabbt pull requests ska granskas, om det inte redan står

## Checklista inför måndag

- [ ] Allt från läxan i pass 3 är klart
- [ ] Alla i gruppen kan starta projektet enligt README
- [ ] De översta korten i backloggen är redo: acceptanskriterier och storlek
- [ ] Ni har valt den första storyn att bygga tillsammans
- [ ] Product Owner och Scrum Master för sprint 1 är bestämda
- [ ] Gruppkontraktet säger när ni har standup och vem som loggar
