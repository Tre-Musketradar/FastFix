# Definition of Done (utkast)

Ska gås igenom och godkännas av hela teamet i Sprint 0. Listan hålls kort med flit och utökas i retron när det behövs.

En story är klar när:

1. Alla acceptanskriterier är uppfyllda och testade för hand.
2. Koden har gått via en pull request till `staging` och CI är grönt.
3. Pull requesten är granskad och godkänd av minst en annan i teamet.
4. Applikationen startar och körs utan fel efter mergen.
5. Det finns inga `console.log`, utkommenterad kod eller TODO kvar i ändringen.
6. README eller `docs/` är uppdaterad om ändringen påverkar hur man startar eller använder projektet.
7. Kortet på boarden är flyttat till "Klart".
